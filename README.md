# AgileSprint Agents

《基于多智能体协同的敏捷开发任务管理系统》的本地运行版本。本目录与旧项目完全独立。

## 已实现

- 管理员登录、项目与迭代创建、模拟开发团队能力展示；
- 管理员可新增开发成员 Agent、手动重分配任务，并创建下一次迭代；
- 四角色协作时间线、状态机、任务拆分、分配、测试退回、项目经理仲裁与复盘；
- 未配置模型时的明确“演示协同模式”；
- DeepSeek、通义、智谱、OpenAI、豆包网页配置；API Key 本机加密保存与删除；
- 真实模型协作顺序：项目经理 → 每个开发成员 → 项目经理仲裁 → 开发成员逐文件代码提案；
- 支持接入整个项目文件夹或单个文件；模型只能在接入范围内提交新建/覆盖文件提案，管理员逐项批准或跳过；
- 在管理员确认后执行 Python `pytest`；测试失败由测试 Agent 分析并交给开发 Agent 持续生成修复提案，管理员可随时介入或停止；
- 生成协作复盘 Markdown、Word 测试报告和 Excel 任务表；
- SQLite 本地持久化，可后续替换为 MySQL。

## 本地运行

1. 安装 Python 3.10 或更高版本，并确保命令行能运行 `py -3 --version`。
2. 双击 [run.bat](run.bat)，首次启动会创建 `.venv` 并安装依赖。
3. 浏览器访问终端显示的地址，默认是 `http://127.0.0.1:5000`。
4. 登录账号：`admin`；密码：`Admin@12345`。

如使用 PyCharm：打开此文件夹后，将解释器设为 `项目目录\.venv\Scripts\python.exe`，再运行 [app.py](app.py)。不要使用 WindowsApps 中的临时 Python 解释器。

## 真实模型协作

1. 登录后打开“模型与安全”，选择 DeepSeek、通义、智谱、OpenAI 或豆包。
2. 填入 API Key；非 DeepSeek 模型还需填写供应商提供的兼容 OpenAI 接口地址与模型名称。
3. 新建项目，输入具体的迭代目标并点击“启动协同”。

真实模型模式不会在文件修改、执行程序或安装依赖时绕过管理员。模型调用失败会显示错误，不会改用虚构的协作结果。接入项目文件夹后，模型可读取其中的文本源码并提出完整文件内容，但不可能访问文件夹外部内容。

## 答辩演示项目

仓库内已包含一个故意带有测试失败的 Python 演示项目：[club_registration](demo_workspace/club_registration)。在新建项目时将该目录作为“本地项目文件夹”，输入其中 README 给出的需求，即可演示：需求拆分 → 真实模型代码提案 → 管理员审批 → pytest 失败 → 自动修复提案 → 复测通过。

## 当前边界

- Python 是唯一支持测试与修复状态闭环的语言；其他语言只作为后续文件提案扩展。
- 当前文件执行器已实现“新建文件夹、新建文件、项目目录内覆盖文件”审批；删除、批量改动与安装依赖仍将沿用同一审批模型扩展。
- 真实模型流程已覆盖规划、开发成员评估、经理仲裁、代码提案、测试失败分析与修复提案；需由你在网页填写有效 API Key 后进行真实联网联调。

## 开源组件说明

本项目基于 Flask、Bootstrap、SQLAlchemy、Requests、Cryptography、pytest 等开源组件搭建；业务数据库模型、协同协议、页面流程与安全审批逻辑由本项目独立编写。答辩和论文中应如实说明使用的通用开源组件，不应宣称整个系统从零实现所有底层库。
